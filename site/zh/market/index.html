插件市场 · 仅安装 · MVP

给画布装上新能力。

节点插件为 Agent 增加可发现、可调用的工具。市场是一份静态目录：工作台下载插件包，对照这里的 SHA-256 校验，先让你看清它是什么，再在你的电脑上安装。

如何安装

  1. 01

    打开市场

    在工作台中打开 设置 → 插件 → 打开插件市场，下面的列表会出现在应用里。

  2. 02

    下载并复核

    插件包下载后按本目录中的 SHA-256 校验。复核卡片列出 id、版本、大小与描述，此时还没有执行任何代码。

  3. 03

    安装

    确认后节点出现在节点菜单，它的工具可以通过 getNodeTools 发现。Agent 也可以用 getPluginMarket 与 installMarketplacePlugin 完成同样的事。

发布

发布你自己的节点。

一个节点就是一个包：插件定义、Zod 类型的工具、React 视图和一份 agent.md 指南。脚手架生成、构建，然后提交 Pull Request 把它加入目录。这个 MVP 不支持上传。

在仓库中

bun packages/nodeScaffold/scripts/createNode.ts myNode "我的节点"
cd packages/nodes/myNode && bun run typecheck && bun run build
# 然后把它加入 site/src/marketCatalog.json 并运行
node site/buildMarket.mjs

阅读插件开发指南了解约定：一个节点只做一件事；小动词工具；readOnly 标注；有类型的输出。
