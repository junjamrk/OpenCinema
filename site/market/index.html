Plugin market · install only · MVP

Give the canvas new abilities.

Node plugins add tools your agent can discover and call. The market is a static catalog: the workbench downloads a package, checks its SHA-256 against this index, shows you what it is, and only then installs it on your machine.

How to install

  1. 01

    Open the market

    In the workbench open Settings → Plugins → Open plugin market. The list below appears in the app.

  2. 02

    Download and review

    The package is downloaded and verified against the SHA-256 in this index. A review card shows id, version, size and description before anything runs.

  3. 03

    Install

    Confirm. The node shows up in the node menu and its tools become discoverable through getNodeTools. Agents can do the same with getPluginMarket and installMarketplacePlugin.

Publish

Ship a node of your own.

A node is one package: a plugin definition, Zod-typed tools, a React view and an agent.md guide. Scaffold it, build it, open a pull request that adds it to the catalog. Uploads are not supported in this MVP.

From the repository

bun packages/nodeScaffold/scripts/createNode.ts myNode "My Node"
cd packages/nodes/myNode && bun run typecheck && bun run build
# then add it to site/src/marketCatalog.json and run
node site/buildMarket.mjs

Read the plugin development guide for conventions: one node, one job; small verb tools; readOnly annotations; typed outputs.

  • Installing runs plugin code on your machine with workspace access. Install only sources you trust.
  • The catalog is static JSON published by pull request. There is no upload, account or telemetry.
  • Packages are verified by size and SHA-256 against this index; a changed file is refused.
  • Plugins that need FFmpeg, WebGL or a provider still depend on your local setup.
