How it works

Direct. See. Finish.

  1. 01

    Direct

    Select one node, a group of shots, or nothing at all. Describe the change in the composer. The scope is yours to set.

  2. 02

    See

    Your agent works on the same canvas you are looking at. Open an editor, paint a selection, adjust a reference, keep a take you like.

  3. 03

    Finish

    Review every candidate against six checks. Replace only the shot that failed. Render the full cut with its audio track.

Features

One canvas takes a film from idea to final cut.

Canvas

Every asset and every step is a node.

Script, stills, clips, audio, previs, generation, review and the edit plan live on one canvas. Edges are reference relationships. Thirteen node plugins ship built in, from text and media to analysis and generation, plus a collaboration extension.

  • Drop files to create nodes
  • Group, arrange, batch connect, undo
  • Everything the agent does is a visible state change

Scope

You decide what the agent may touch.

The composer acts on your selection: one node, a marquee of nodes, or the whole canvas. Generation nodes can switch between generating and letting the agent adjust the node itself. References are numbered so you can see what the model will receive.

  • One node, N nodes, or the canvas
  • References shown as numbered chips
  • Manual and agent edits share one undo history

Editors

Change only what matters.

Paint a selection and only that region changes. Crop and transform, split a grid, relight, change the angle, capture a panorama. Trim clips, extract audio, separate tracks, change speed and transcribe, all through local FFmpeg.

  • Image: inpaint, crop, grid split, lighting, angle, panorama
  • Video: trim, frames, audio, speed, frame analysis
  • Results become new nodes; sources stay untouched

Previs

See the shot before you generate it.

Block the action and the camera on a white-model stage. Export RGB, depth and normal layers per shot and freeze them as reference nodes for generation. Previs and depth are references for framing and rhythm, not a motion lock.

  • Characters, set pieces, camera blocking, takes
  • RGB, depth and normal exports per shot
  • Frame analysis, pose tracking and relative depth from real footage

Your models

Your providers. Your keys. Your machine.

Connect Volcengine Ark Seedance, fal, Replicate or any OpenAI-compatible video service, or import a custom provider from a JSON manifest. Credentials live in local settings; agents only ever see whether one is configured.

  • Provider manifests, no code
  • FFmpeg and the depth model prepared explicitly and pinned by hash
  • Go server listens on loopback only

Plan, review, edit

The model proposes. You decide.

01

See the plan first

Before anything is paid for, the generation plan shows the final prompt, the real model parameters and the role of every reference: instruction, identity, composition, motion or exclude.

02

Six checks, your call

Direction, action, identity, continuity, unexpected cuts, deformation and branding. A candidate is approved only when you mark every check and write what you saw. Rejected candidates stay in the project.

03

Replace one shot, keep the rest

The edit plan holds 2 to 16 shots, in and out points, output spec and one audio track. Swap a single shot; the others never move. Rendering creates a new cut and keeps the old one.

The film

Thirty seconds. Every frame drawn in code.

The launch film is built from the same design system as the product. No stock, no generated footage, no screenshots: every interface element is live state rendered frame by frame.

Get started

Build it, open a folder, connect your agent.

0.4.0 is in development. Source builds need Bun 1.3.14+, Go 1.26+ and Node.js 22+. Running a packaged plugin needs Node.js 22+ only.

Run from source

git clone https://github.com/junjamrk/OpenCinema.git
cd OpenCinema
bun install --frozen-lockfile
bun run build
bun start

Open http://127.0.0.1:47920 and point it at any folder.

Connect Claude Code

claude --plugin-dir ./build/openCinema
# then
/opencinema:opencinema

Codex: codex plugin add opencinema@openCinemaStandalone. Any MCP client can copy the connection from the settings panel.

Open source

Built in the open.

MIT licensed. A Go server, a React canvas, a framework-independent editing session and a node SDK, all in one repository. Issues, pull requests and node plugins are welcome.

Write a node

A node is a package that exports a plugin definition and registers Zod-typed tools. Your UI and the agent call the same implementation.

Add a provider

A service that speaks an existing protocol needs only a JSON manifest. Unmapped references are refused, not dropped.

Shape the tools

Every tool has a live schema, output validation and annotations. Errors carry a machine code and a recovery action.

Open an issue

  • 0.4.0 is in development and unreleased.
  • AI generation uses providers you configure and may cost money. No host subscription includes a video model.
  • Previs, white model and depth are references. Motion analysis tracks pose and 2D camera motion, not a 3D solve.
  • Review is a recorded decision made by a person.
