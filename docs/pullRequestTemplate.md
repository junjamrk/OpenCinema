# Pull Request 模板

## 问题与结果

描述具体触发条件、修改前后行为和本次范围。关联实际问题链接；没有远端时不填虚构链接。

## 实现与边界

说明修改的公共入口、插件归属、入参／版本／保存／恢复边界及兼容影响。不要把内部过程或未采用方案当成最终实现。

## 实际验证

记录明确执行的既有 typecheck／构建命令及结果，必要手工 UI 和 Agent 流程、真实产物、保存与回读。区分未执行、阻塞和通过；构建通过不代替宿主与内容验收。遵守 [贡献规范](../contributing.md)，不新增测试／自检代码或测试 CI。

## 发布影响

列出 manifest／版本／平台／依赖／第三方许可变化和已知限制。确认未加入密钥、认证文件、运行数据、私密工程或机器专属路径。供应商费用、上传与外部发布仍需相应授权。
