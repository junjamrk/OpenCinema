# 文本节点

使用 Markdown 编写、保存和生成正文，可用于剧本、分镜说明或素材分析。

## 输入与输出

- 输入支持文本、图片和视频参考。
- 输出节点当前的完整 Markdown 字符串，可连接支持文本输入的下游节点。

## 使用方法

1. 节点内以 Markdown 预览正文；点击“编辑”打开富文本编辑器，也可切换到原文编辑 Markdown。
2. 需要 AI 创作时，选中节点，在画布底部输入要求并发送给已连接的宿主 Agent。
3. 可连接参考节点，在提示词中说明如何使用这些参考内容。
4. 宿主可返回正文或调用节点的 `setText` 保存；委托受理与实际正文完成分别报告。
5. 生成结束后可继续手工编辑，再将文本输出连接到后续制作节点。

正文自动保存为节点资产中的 Markdown 版本文件，下载使用 `.md` 格式。磁盘内容发生冲突时，可先查看并复制当前正文，再选择重新读取磁盘。

节点自带 Markdown 编辑和预览实现。富文本编辑会规范化 Markdown；需要保留原始 HTML 写法时，请使用原文模式。

图片、视频、音频和文件参考的理解能力由宿主 Agent 提供；无需配置平台通用语言模型。
