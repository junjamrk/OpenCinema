# 图片生成节点

根据提示词生成图片，也可使用已有图片和文本作为参考，制作角色、场景或分镜图。

## 输入与输出

- 输入支持图片和文本；连接的文本会作为生成要求的一部分。
- 输出一张生成图片，可继续用作图片或视频生成的参考。

## 使用方法

1. 默认由已连接的宿主 Agent 生成；已有专项图片供应商配置时，也可选择节点专项模型。
2. 选中节点，在画布底部输入画面要求，按需连接图片或文本参考，并在指令中引用它们。
3. 点击比例与分辨率区域，选择当前模型提供的选项。
4. 从底部发送指令；生成过程中可停止任务。
5. 完成后在节点内查看结果，选中节点可从上方下载或放大预览。

参考顺序由画布连线决定。连接的节点需要已有内容，修改要求或设置不会自动重新生成。宿主受理时显示委托状态，实际工作区产物通过 `setImage` 写入；专项模型费用由供应商决定。
